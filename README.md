# YurichHub

Сайт-хаб: Sevastopol AI, City Code, Crimea RWA — плюс курс по RWA, глоссарий и офер ЦФА.

Открывается здесь: [yurich-citycode.github.io/YuRichHUB](https://yurich-citycode.github.io/YuRichHUB/)

## Страницы

| Страница | Что на ней |
| --- | --- |
| `index.html` | Главная: направления, проекты, City Code, ссылки |
| `course.html` | Курс «RWA с нуля» — шесть модулей |
| `glossary.html` | Глоссарий терминов |
| `cfa.html` | Офер ЦФА: калькулятор выплат и стресс-тесты |
| `privacy.html` | Политика обработки персональных данных (бот, клуб, канал) |
| `suggest.html` | Форма «✍️ Предложить место» для бота: заявка уходит владельцу через Cloudflare Worker (`WORKER_URL` внутри файла) |

## Стиль

Шрифты лежат на сайте в `fonts/` (`fonts/fonts.css`), Google Fonts не нужен. У всех шрифтов есть кириллица.

- Заголовки: Oswald 700 (`var(--yh-display)`)
- Текст: Inter (`var(--yh-sans)`)
- Метки и цифры: JetBrains Mono (`var(--yh-mono)`)
- Тёмные страницы (главная, политика, форма): фон `#0A0A0A`, лайм `#D7FF3D`, золото `#C8A24A`
- Светлые страницы (курс, глоссарий, ЦФА): бумага `#F1E9D8`, чернила `#18140F`, розовый `#E8377E`

Шрифты распространяются по лицензии SIL Open Font License 1.1.
