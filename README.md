# YurichHub

Сайт-хаб: Sevastopol AI, City Code, Crimea RWA — плюс курс по RWA, глоссарий и офер ЦФА.

Открывается здесь: [yurich-citycode.github.io/YuRichHUB](https://yurich-citycode.github.io/YuRichHUB/)

## Страницы

| Страница | Что на ней |
| --- | --- |
| `index.html` | Главная: направления, проекты, City Code, ссылки |
| `course.html` | Курс «RWA с нуля» — шесть модулей |
| `glossary.html` | Глоссарий терминов |
| `cfa.html` | Офер ЦФА: калькулятор выплат и стресс-тесты |
| `privacy.html` | Политика обработки персональных данных (бот, клуб, канал) |
